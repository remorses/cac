# How to connect Framer MCP server

> **Note:** All code snippets below already include your user session ID and secret. Do not share these URLs with others.

> **⚠️ Important:** Using **Framer MCP** requires that the _Framer MCP plugin is open inside the Framer app_. Only one MCP plugin can be open at any time—the server will control whichever Framer project currently has the plugin open.

## Cursor

export const cursorCode = `{
  "mcpServers": {
    "framer": {
      "type": "sse",
      "url": "https://mcp.unframer.co/sse?id=$userId&secret=$secret"
    }
  }
}`

<CodeBlock title='.cursor/mcp.json' language='json'>
    {cursorCode}
</CodeBlock>

1. Save to project root (or `~/.cursor/mcp.json`).
2. Restart Cursor → _Agent_ mode detects the tool.
3. Ask in the agent panel "What tools do you have available?" to make sure the Framer MCP is connected.
4. Enable the Framer MCP tool in Cursor settings if still disabled, in the tools & integrations section.

## Claude Code

Use the following command to add Framer MCP when calling Claude cli from the current working directory

export const claudeCliCommand = `claude mcp add --transport sse -s project framer "https://mcp.unframer.co/sse?id=$userId&secret=$secret"`

> IMPORTANT! You MUST use the quotes around the url or Claude will incorrectly miss some query params!

<CodeBlock title='CLI' language='bash'>
    {claudeCliCommand}
</CodeBlock>

This generates the following file:

export const claudeMcpConfig = `{
  "mcpServers": {
    "framer": {
      "type": "sse",
      "url": "https://mcp.unframer.co/sse?id=$userId&secret=$secret"
    }
  }
}`

<CodeBlock title='.mcp.json' language='json'>
    {claudeMcpConfig}
</CodeBlock>

> IMPORTANT! Notice that the above config and command will only make the Framer MCP available when you call `claude` cli in the same directory as the `.mcp.json` file.
> If you want to make the MCP always available you can omit the `-s project` from the command, this is usually not best practice because it makes it more difficult to manage currently available MCPs

## Claude Desktop app **without** a Max subscription

Without a Max subscription you won't be able to connect remote MCP currently in Claude. You can instead add the following config in the Claude Desktop app MCP settings instead:

export const claudeAppMcpConfig = `{
  "mcpServers": {
    "framer": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.unframer.co/sse?id=$userId&secret=$secret",
        "--transport",
        "sse-only"
      ]
    }
  }
}`

## Programmatic control via OpenAI JS SDK (Responses API)

export const agentCode = `import { Agent, hostedMcpTool } from "@openai/agents";

const framerTool = hostedMcpTool({
name: "framer",
serverUrl: \`https://mcp.unframer.co/sse?id=\${process.env.USER_ID}&secret=\${process.env.SECRET}\`,
});

const agent = new Agent({
model: "gpt-4o-responses",
tools: [framerTool],
});

const result = await agent.run("Publish the current page to production");
console.log(result.output.text);`

<CodeBlock title='agent.ts' language='ts'>
    {agentCode}
</CodeBlock>

> The agent streams _tool calls_ to Framer’s MCP server and returns status when complete.

### Troubleshooting: Connection Timeout

If you get a "connection timeout" error, install mcp-remote globally and update your config:

```bash
npm i -g mcp-remote
```

Then update your `~/.codex/config.toml` to use `mcp-remote` directly:

export const codexCliConfigAlt = `[mcp_servers.framer]
command = "mcp-remote"
args = ["https://mcp.unframer.co/sse?id=$userId&secret=$secret", "--transport", "sse-only"]`

## How to Check MCP Availability

You can check if the Framer MCP server is connected and accessible from your AI assistant or tool. To do so:

1. **Ask directly:**
   Try prompting your assistant with a question like:

    > _Do you have access to the Framer MCP tool?_

    The assistant should confirm if the tool is available. If not, review your configuration above.

2. **Try a simple action:**
   Ask the assistant to perform a basic operation using the Framer MCP tool. For example:

    > _Rewrite the current page text_

    If the integration is successful, the tool should respond or attempt the requested action. If you receive an error about tool access, double‑check that the Framer MCP plugin is open and your configuration matches the appropriate section above.

## Troubleshooting Cheatsheet

| Symptom                          | Quick Fix                                                                       |
| -------------------------------- | ------------------------------------------------------------------------------- |
| Time‑outs / Very Slow            | Ensure the **Framer MCP plugin is open**. If hung, close and reopen the plugin. |
| App does not see the Framer MCP  | Make sure to open the Framer MCP plugin **before** you open Cursor or Claude    |
| MCP loading fails in Claude Code | Make sure you used quotes " around the url in the `claude mcp add` command      |
| Switch projects                  | Close the MCP plugin in the current project and open it in the target project   |
| Cursor can’t see server          | Ensure _Agent mode_ enabled and Pro subscription active                         |
| Copilot doesn’t list server      | Update to VS Code 1.102+ and enable preview flag                                |
